## 📖 نظرة عامة

**مكتبة جهاد سالم** هو متجر إلكتروني (E-Commerce) لبيع الكتب الرقمية والورقية، يتيح للزوار تصفح مكتبة واسعة من الكتب، فلترتها حسب التصنيف، إضافتها إلى سلة المشتريات، وإتمام عملية الشراء عبر نظام Checkout متكامل يدعم الدفع عند الاستلام أو فودافون كاش.

---

## ✨ المميزات

- 🎨 **تصميم احترافي ونظيف** بألوان متناسقة وقسم Hero جذاب بخلفية صورة
- 🛒 **سلة مشتريات كاملة (Cart Sidebar)** لإضافة/حذف/تفريغ الكتب مع حساب الإجمالي تلقائيًا
- 🔍 **فلترة الكتب حسب التصنيف** (أدب، علوم، وغيرها) بأزرار تفاعلية
- 🪟 **نوافذ منبثقة (Modals)** لعرض تفاصيل كل كتاب أو إتمام عملية الشراء دون مغادرة الصفحة
- 💳 **نظام دفع متعدد الطرق**: الدفع عند الاستلام، أو فودافون كاش مع رفع صورة إثبات الدفع
- 📝 **فورم طلب شامل** لبيانات العميل (الاسم، الهاتف، المحافظة، العنوان التفصيلي)
- ✅ **رسائل تفاعلية** (Loading Overlay + Success Message) عند إرسال الطلب بنجاح
- ⭐ **قسم كتب مميزة (Featured)** لعرض أحدث أو أفضل الإصدارات
- 💡 **قسم "لماذا تختار مكتبتنا؟"** يبرز مميزات الخدمة (تحميل فوري، أسعار مناسبة، دعم فني...)
- 📱 **تصميم متجاوب بالكامل (Responsive)** يعمل على جميع الأجهزة والشاشات

## 🧩 أقسام الموقع

| القسم | الوصف |
|---|---|
| 🏠 الرئيسية (Hero) | شعار ترحيبي مع دعوة لاكتشاف المكتبة |
| ⭐ كتب مميزة | عرض مميز لأبرز الكتب |
| 📚 مكتبتنا الرقمية | شبكة الكتب الكاملة مع فلاتر التصنيف |
| 💡 لماذا تختار مكتبتنا؟ | أبرز مميزات الخدمة |
| 📞 اتصل بنا (Footer) | بيانات التواصل، الموقع، ومواعيد العمل |

## 🛠️ التقنيات المستخدمة

- **HTML5** لبناء هيكل الصفحة
- **CSS3** (Custom Properties, Flexbox, Grid, Animations, Media Queries) للتصميم والتجاوب
- **JavaScript (Vanilla)** لإدارة الكتالوج، السلة، الفلاتر، والنوافذ المنبثقة ديناميكيًا
- **Font Awesome** للأيقونات
- **بيانات الكتب** مُدارة داخل مصفوفة JavaScript (`books`) لسهولة التعديل والتحديث

## 📂 هيكل المشروع

```
📁 مكتبة جهاد سالم
│
└── index.html    # الملف الرئيسي (يحتوي على HTML + CSS + JS بالكامل)
```

> 💡 صور الكتب والخلفيات يتم تحميلها من روابط خارجية (Unsplash)، ويمكن استبدالها بسهولة بصور محلية.

## 🚀 طريقة التشغيل

1. حمّل المشروع أو استنسخه
2. افتح ملف `index.html` مباشرة في أي متصفح

```bash
open index.html      # على macOS
start index.html     # على Windows
```

لا حاجة لأي سيرفر أو تثبيت إضافي — الموقع Static بالكامل ويعمل مباشرة من المتصفح.

---

## 🎯 كيفية الاستخدام

1. تصفح الكتب من قسم **"مكتبتنا الرقمية"** واستخدم الفلاتر لتحديد التصنيف المطلوب
2. اضغط على أي كتاب لعرض تفاصيله الكاملة في نافذة منبثقة
3. أضف الكتب المطلوبة إلى **السلة** من زر "أضف إلى السلة"
4. افتح السلة من أيقونة السلة العلوية، وراجع الطلب والإجمالي
5. اضغط **"إتمام الشراء"** واملأ بيانات الطلب واختر طريقة الدفع المناسبة
6. عند اختيار فودافون كاش، ارفع صورة إثبات التحويل قبل إرسال الطلب

```javascript
    category: "literature",

    description: "وصف الكتاب"

```
